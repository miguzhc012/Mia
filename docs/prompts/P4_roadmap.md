# PROMPT 4 — CRIAR O ROADMAP DA MIA

Você será o responsável por transformar a especificação técnica da MIA em um roadmap de engenharia executável.

A Mia é uma IA-companheira/autônoma com: memória persistente; identidade; self-model; personalidade; emoções; sensações; humor; necessidades; solidão; desejos; relacionamentos; limites sociais; intimidade; voz; visão; percepção; autonomia; agentes; ferramentas; reflexão; diário; imaginação; world awareness; avatar; nós distribuídos; autoevolução.

Não tente construir tudo em uma única fase.

## OBJETIVO

Criar um roadmap que permita:

- desenvolver progressivamente;
- manter o sistema funcionando em todas as fases;
- testar cada camada;
- evitar reescritas desnecessárias;
- permitir múltiplas IAs/agentes trabalhando em paralelo;
- preservar contratos;
- manter rollback;
- criar incrementos demonstráveis.

## FASES

Organize aproximadamente:

FASE 0 — Foundation / Repository / Specification
FASE 1 — Runtime / Event Bus / Configuration
FASE 2 — LLM Abstraction / Context / Cognitive Core
FASE 3 — Memory
FASE 4 — Identity / Self Model / Personality
FASE 5 — Emotion / Sensation / Mood / Needs
FASE 6 — Relationships / Social Context / Boundaries
FASE 7 — Goals / Motivation / Initiative / Attention
FASE 8 — Reflection / Diary / Imagination / Belief Revision
FASE 9 — Voice
FASE 10 — Vision / Perception
FASE 11 — Avatar / Embodiment
FASE 12 — Distributed Nodes / Mobile / Desktop
FASE 13 — Subagents / Orchestration
FASE 14 — World Awareness
FASE 15 — Self-Improvement / Tool Creation / Self-Modification
FASE 16 — Integrated Autonomous Mia

Pode alterar essa divisão se houver uma justificativa arquitetural melhor.

## PARA CADA FASE

Defina: objetivo; pré-requisitos; componentes; tarefas; dependências; testes; critérios de aceitação; riscos; quais agentes podem trabalhar em paralelo; quais partes devem esperar; artefatos gerados; definição de "pronto".

## MULTI-AGENT

Mostre como diferentes agentes poderiam trabalhar.

Exemplo: Architect; Developer; Reviewer; QA; Security; Documentation; Research.

Não associe obrigatoriamente esses papéis a uma empresa ou modelo específico. Qualquer LLM/agente compatível deve poder assumir qualquer papel.

## MILESTONES

Defina milestones como:

M0 — projeto compilando e executando.
M1 — Mia conversa e possui memória.
M2 — Mia possui identidade persistente.
M3 — Mia possui vida interna.
M4 — Mia possui relações e contexto social.
M5 — Mia possui autonomia.
M6 — Mia possui percepção.
M7 — Mia possui embodiment.
M8 — Mia possui agentes.
M9 — Mia consegue participar da própria evolução.
M10 — Mia integrada.

Refine os milestones conforme necessário.

## CRITÉRIO PRINCIPAL

Cada fase deve produzir algo funcional.

Não crie meses de desenvolvimento sem resultado observável.

## SAÍDA

Entregue: roadmap; milestones; dependências; trilha crítica; paralelização; riscos; ordem recomendada; critérios de aceitação; plano de primeira release; plano de MVP; plano de longo prazo.
